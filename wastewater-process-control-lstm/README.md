# wastewater-process-control-lstm (东阳污水处理厂 AI 预测预警与运行自适应控制优化系统)

本项目基于深度时序预测模型与前馈-反馈闭环预测控制 (MPC)，实现污水处理厂的低碳节能加药与曝气自动寻优。

## 💡 核心功能与技术实现

1.  **互相关分析 (CCF) 时滞标定**：
    污水厂流程超长。通过互相关函数 $r(k)$ 系统性滑移计算 SCADA 进水水质与出水 TN/TP/NH3-N 的滞后步数。标定出物理传输与生化降解的整体时滞常数在 15.0 ~ 20.5 小时之间。
2.  **12小时 Lookback Window LSTM 预测网络**：
    构建时序前瞻模型，利用 12 小时的进水时序（144个时间步）作为输入，超前 2 小时前瞻预测出水口的 TN、TP 浓度，克服事后反馈控制（超标后再调节）带来的工艺监管超标风险。
3.  **SCADA 时序级联滤波**：
    采用中值滤波自动剔除仪表清洗死值和跃迁尖峰，配合滑窗均值滤波平滑工艺波动。
4.  **模型预测控制 (MPC) 与 ASM1 动力学优化**：
    根据预测出的水质指标，利用遗传优化算法，动态自动调小夜间低谷期碳源醋酸钠与 PAC 除磷药剂投加阀门（降低加药量 15% 以上），并动态下调好氧池末端 DO 曝气风量，避免高浓度 DO 随内回流带回缺氧区抑制硝化反应，实现低碳运行。
