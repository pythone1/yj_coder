## 2. 算法核心公式
- 总量约束：`Q_R = Σ_i ∫ I_i(t) dt`
- 份额约束：`x_i >= 0, Σ_i x_i = 1`
- 节点总量：`q_i = x_i * Q_R`
- 节点逐时注水：`I_i(t) = x_i * Q_total(t)`
- 适应度：`Mean NSE = (1/m) * Σ_j NSE_j`
- 轮盘赌：`p_k = f_k / Σ_r f_r`
- AM proposal：`Y ~ N(theta_n, C_n)`
- 协方差：`C_n = sd * Cov(X_0,...,X_n-1) + sd * eps * I`
- 缩放：`sd = 2.42 / d = 0.121`
- 接受率：`alpha = min(1, L(Y)/L(theta_n))`
