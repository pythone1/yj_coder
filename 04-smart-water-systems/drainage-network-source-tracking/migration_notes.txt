`baseline`
`clean`
`dry`
`旱天`
`基线`
`no_`

事件模型文件名包含以下关键词时会被自动识别：
`event`
`injection`
`rain`
`wet`
`雨天`
`注水`
`入流`

四、必须人工确认的配置
打开：
`code/config_0416.py`

确认以下变量：
1. `MODEL_1D_INP`
   旱天基线模型。

2. `MODEL_2D_INP`
   雨天事件模型或含真值注水模型。

3. `CANDIDATE_NODES`
   新管网候选井列表。

4. `MONITOR_NODES`
   新管网监测井列表。

5. `TRUTH_INJECTION_NODES`
   新管网真值注入点。

6. `OUTFALL_NODE`
   排口节点。

7. `STEP_MINUTES`
   数据时间间隔。

五、运行顺序
1. 构造数据
`conda run -n LSTM python code\build_0416_data.py`

2. 小参数检查
`conda run -n LSTM python code\run_small_0416.py`

3. 中参数运行
`conda run -n LSTM python code\run_medium_0416.py`

4. 大参数运行
`conda run -n LSTM python code\run_large_0416.py`
