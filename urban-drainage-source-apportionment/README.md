# urban-drainage-source-apportionment (城市排水管网入流异常溯源与定位分析系统)

本系统是基于物理水力模拟与后验概率分布估算结合的管网反演寻优项目。

## 💡 算法架构

1.  **水力学前向解算 (SWMM)**：
    使用 Python 接口调用 `swmmh5.dll` 动态链接库。加载包含管径、坡度、检查井等拓扑结构的管网模型文件。运行 36 小时、10 分钟时间分辨率的降雨/异常排污动态水流模拟，得到 9 个监测井上的流量、水位和流速时序基线。
2.  **两阶段反演优化 (GA + AM-MCMC)**：
    *   **第一阶段：遗传算法 (GA)**：设计适应度函数为 9 个监测点模拟值与实测值之间的平均纳什系数 (NSE)，通过选择、交叉和变异算子快速筛除明显不相干的入流节点组合。
    *   **第二阶段：自适应大都会算法 (AM-MCMC)**：在 GA 缩小后的 20 个候选节点空间中，应用自适应协方差矩阵调整机制进行马尔可夫链采样。8 条独立链，每条链采样 700 步（前 180 步预热），自适应调整提议步长（链接受率控制在 0.233~0.290），最终推导出 5 个真值污染源注入比例的后验概率密度分布。
3.  **代偿路径 (Compensation) 分析**：
    计算各节点间的协方差，自动识别出下游流路重合时的“代偿点”（如 103 点与 308 点对于下游 267 点的响应极其相似），从而给出概率排查权重。

## 📁 运行方式
```bash
# 运行溯源优化解算主脚本
python simulate_apportionment.py
```
