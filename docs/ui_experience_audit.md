# UI 体验审查与移动端适配记录

日期：2026-06-24

## 审查范围

- 全局框架：侧边栏、顶部栏、全局搜索、页面容器。
- 核心工作区：在线简历编辑器、数据中心、知识雷达、作品集、模拟面试。
- 移动端断点：992px、760px、720px、576px。

## 当前结论

项目已经从内容集合变成了可操作的求职工作台：导航清楚，数据中心具备备份恢复、用户配置、岗位匹配和报告导出，简历页具备状态栏、评分与区块跳转。

仍需继续推进的方向是：减少移动端横向拥挤、提升侧栏打开/关闭的确定性、让关键操作按钮在窄屏具备稳定触控尺寸，并逐步补充真实浏览器截图回归。

## 本轮已修复

- 移动端侧边栏增加遮罩层，点击遮罩可关闭导航。
- 移动端菜单打开时锁定页面滚动，避免主内容跟随滚动。
- 删除底部脚本控制菜单按钮显示的逻辑，改为 CSS 断点控制。
- 侧边栏切换页面后同步关闭遮罩，避免残留遮挡。
- 小屏顶部搜索框改为更稳定的宽度与触控高度。
- 小屏数据中心、岗位匹配、简历导出等按钮改为单列全宽，减少误触。
- 简历纸张在小屏保持固定最小宽度，外层横向滚动，避免 A4 排版被挤坏。
- 简历编辑侧栏在平板/手机上移到主内容前方，减少上下文丢失。
- 简历编辑器新增会话内撤销/恢复，覆盖文字编辑、AI 润色采纳、ATS 优化、增删条目、调整排序和导入配置等高风险操作。
- 简历编辑器新增持久化版本历史，关键版本可手动保存、恢复、删除，并随全量备份导出。
- 知识库深度卡新增复制整卡、复制面试话术和复制代码片段，提升背诵、投递和面试复用效率。

## 仍建议后续处理

- 增加 Playwright 或等价截图检查，至少覆盖 390px、768px、1440px 三档。
- 为数据中心增加“最近一次备份/最近一次岗位分析”的状态提示。
- 为简历编辑器继续补充版本差异对比，当前已支持会话撤销/恢复和持久化快照。
- 将全局搜索结果增加键盘上下选择，而不仅是回车进入第一条。
- 为知识库复制操作继续增加“加入背诵清单”或“生成面试问答卡”的串联能力。

## 验收建议

- 390px 宽度下：顶部搜索、菜单按钮、数据中心操作按钮不横向溢出。
- 768px 宽度下：简历控制侧栏在正文前方，简历纸张可横向滚动查看。
- 1440px 宽度下：侧栏固定、数据中心两列布局、知识雷达双栏布局保持。
- 任意宽度下：打开侧栏后点击遮罩能关闭，切换页面后遮罩不残留。
