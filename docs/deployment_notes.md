# 部署说明

## 当前形态

本项目当前是纯前端静态应用，入口为 `index.html`，业务数据写在 `js/*.js` 中，用户编辑状态保存在浏览器 `LocalStorage`。

## 本地运行

```bat
py -3 -m http.server 8000
```

访问：

```text
http://localhost:8000
```

## 静态托管

可直接部署到 GitHub Pages、Vercel、Netlify、Cloudflare Pages 或任意静态文件服务器。需要保留以下目录：

- `index.html`
- `css/`
- `js/`
- `docs/`（可选）
- `*.pptx`、`*.html` 等展示资产（可选）

## 数据持久化

当前用户数据只存在当前浏览器内。换浏览器或清缓存会丢失本地编辑状态。

已新增“数据中心”用于：

- 查看本地数据项和占用。
- 导出全量 JSON 备份。
- 从全量备份恢复。
- 保存候选人、目标岗位、薪资和默认导出格式。
- 自动生成并导出求职材料报告。
- 清空本地编辑数据。

## 后续服务化路线

1. 后端 API：保存简历版本、作品集配置、知识库收藏和学习进度。
2. 数据库：用 SQLite/PostgreSQL 存结构化数据，用对象存储放头像、PPT、导出文件。
3. 鉴权：加入本地管理员账号或轻量登录。
4. 检索：把简历证据、投标文件、项目文档接入向量检索。
5. 自动报告：根据用户配置生成简历、作品集报告和岗位匹配清单。
