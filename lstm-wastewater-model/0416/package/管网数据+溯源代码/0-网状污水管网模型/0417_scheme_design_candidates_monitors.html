设计判断

候选井保留20个，并强制包含 J20、J48、J11；其余候选按管网无向距离做远距覆盖，避免把一串相邻井都放进候选集导致代偿。
监测井选11个，不放在注入井本身；重点放在 J20 到 J48 之前、J48 到 J7 之前、J11 到 J7 之前，以及 J7 后共同下游。
