## 2. 生产数字大脑总览页

**标题**
从人工经验到数字大脑：生产AI不是单点模型

**页面主句**
白酒生产AI的核心，不是给每个环节各做一个模型，而是把老师傅经验、现场数据、算法判断和工艺执行连成一条持续进化的生产神经网络。

**展示文字**
- 人工经验：工艺员通过温度、湿度、酒醅状态、设备声音、产线节拍判断问题。
- 数据感知：传感器、PLC/SCADA、MES/WMS、质检、工单和人工记录形成生产数据底座。
- 算法判断：时序预测、视觉检测、异常识别、路径优化和规则推理识别风险与机会。
- 工艺动作：输出预警、推荐参数、质检判定、维修窗口、AGV调度和仓储排程。
- 效果反馈：质量、产量、停机、误检、等待、发货效率回流，推动模型持续迭代。

**五大场景入口**
酿酒指挥中心 / 包装智能质检 / 设备预测性维护 / AGV路径优化 / 仓储物流优化

**图中可用标签**
经验沉淀 -> 数据感知 -> 算法建模 -> 工艺执行 -> 效果反馈

## 3. 酿酒指挥中心

**标题**
酿酒指挥中心：让发酵黑盒变成可解释的工艺地图

**页面主句**
通过历史优秀批次、实时工艺数据和专家经验融合，AI把“凭感觉调工艺”升级为“有依据地选工艺、调参数”。

**行业痛点**
- 酿造过程周期长、变量多，质量波动往往到出酒后才被发现。
- 老师傅经验价值高，但难以结构化沉淀、复制和传承。
- 温湿度、粮曲配比、蒸汽压力、入窖条件、发酵曲线之间存在复杂耦合。

**算法逻辑**
- 预警：LightGBM / XGBoost识别批次异常，LSTM / TCN / TFT预测温度、湿度和发酵趋势。
- 选优：相似批次检索优秀历史工况，结合贝叶斯优化推荐参数窗口。
- 调参：输出推荐参数、推荐理由、相似批次依据和风险提示，由工艺人员确认执行。

**工艺链路**
制曲 -> 润粮 -> 上甑 -> 蒸馏摘酒 -> 摊晾 -> 入窖 -> 发酵 -> 出窖评价

**效益表达**
- 提前发现批次偏离，减少事后追溯。
- 复用优秀批次经验，提高质量稳定性和优级酒率。
- 形成企业专属工艺知识库，为后续工艺大模型打基础。

## 4. 包装智能质检

**标题**
包装智能质检：从人工目检升级为高速在线识别

**页面主句**
质检AI的核心不是“拍一张图”，而是用稳定光学工艺、缺陷样本库和在线模型，把缺陷识别嵌入产线节拍。

**行业痛点**
- 包装线速度高，人工目检容易疲劳，质量一致性难保证。
- 外观缺陷类型多，涉及瓶盖、标签、喷码、液位、盒箱等多个位置。
- 酒体悬浮异物检测受瓶身曲面、反光、气泡和酒液晃动影响，难度高。

**算法逻辑**
- 外观检测：YOLO / Mask R-CNN / ViT识别瓶盖歪斜、标签缺失、喷码异常、液位偏差。
- 异物检测：背光、侧光、偏振光、多角度成像结合视频目标检测和轨迹分析。
- 异常学习：PatchCore等少样本异常检测用于缺陷样本不足场景。

**工艺链路**
触发拍照 -> 多光源成像 -> 缺陷识别 -> NG剔除 -> 人工复核 -> 缺陷图库回流

**效益表达**
- 降低人工目检压力，提高高速产线稳定性。
- 建立缺陷图库，按批次、供应商、设备和班组追溯问题来源。
- 酒体异物检测先用样机验证误检率、漏检率和节拍，再逐步上线。

## 5. 设备预测性维护

**标题**
设备预测性维护：从“坏了再修”变成“提前知道”

**页面主句**
通过设备运行时序数据和维修工单融合，AI识别状态劣化趋势，提前给出维修窗口和备件建议。

**行业痛点**
- 关键设备突发停机会直接影响包装、灌装、仓储和物流节拍。
- 故障前兆隐藏在振动、电流、温度、压力等连续变化中，人工难以及时发现。
- 维修经验依赖个人，工单数据没有充分转化为可复用知识。

**算法逻辑**
- 健康画像：区分开机、稳定运行、换型、清洗、停机等不同工况。
- 异常检测：Isolation Forest / One-Class SVM / LSTM Autoencoder识别异常波动。
- 故障预测：XGBoost / 随机森林 / Transformer时序模型预测故障概率和剩余寿命。

**工艺链路**
设备采集 -> 工况识别 -> 健康评分 -> 异常预警 -> 维修建议 -> 工单反馈

**效益表达**
- 减少突发停机，提升关键产线可用率。
- 提前安排保养和备件，降低抢修成本。
- 沉淀设备故障知识库，提高维修决策效率。

## 6. AGV路径优化

**标题**
AGV路径优化：让厂内物流节拍跟上生产节拍

**页面主句**
AGV效率问题通常不是单车不聪明，而是任务释放、车辆分配、节点拥堵和路径冲突没有统一优化。

**行业痛点**
- 多车同时运行时，等待、绕路、堵点和充电策略会放大整体低效。
- WMS/MES任务释放节奏与AGV执行能力不匹配，容易出现局部拥堵。
- 直接上线新调度策略风险高，需要先用仿真验证。

**算法逻辑**
- 路径规划：A* / Dijkstra在地图拓扑上生成可行路径。
- 任务分配：OR-Tools、遗传算法、蚁群算法优化车辆和任务匹配。
- 冲突消解：引入时间窗和节点占用，降低会车、等待和死锁风险。

**工艺链路**
任务生成 -> 车辆分配 -> 路径规划 -> 冲突消解 -> 执行监控 -> 仿真回放

**效益表达**
- 减少AGV等待、空驶和绕行。
- 提高任务准时率和厂内物流吞吐。
- 通过仿真先验证策略，降低真实上线风险。

## 7. 仓储物流优化

**标题**
仓储物流优化：把订单、库位、装车和配送一起算

**页面主句**
仓储物流优化不是简单排路线，而是把库存位置、订单组合、车辆约束和客户时间窗统一建模。

**行业痛点**
- 多仓库装货、多客户混装、临时订单和库位分散会拉长发货时间。
- 人工排程依赖经验，难以同时兼顾装载率、时效和路线成本。
- 仓库内部拣选路径、月台排队和车辆路径往往割裂优化。

**算法逻辑**
- 库位优化：ABC分类、SKU关联度和出库频次计算库位评分。
- 波次排程：根据客户、路线、时间窗和产品组合生成拣选波次。
- 路径优化：VRP / MDVRP / VRPTW模型结合OR-Tools、ALNS、VNS求解。

**工艺链路**
订单进入 -> 库位推荐 -> 波次拣选 -> 装车排序 -> 配送路径 -> 成本反馈

**效益表达**
- 缩短装车发货时间，减少车辆等待。
- 提高库位利用率、车辆满载率和配送效率。
- 让仓储调度从人工排程升级为可解释、可调整的优化系统。

## 8. 实施路线页

**标题**
先建样板，再扩场景，最后形成闭环智能

**页面主句**
生产AI落地不能一上来追求全自动，应先做可验证、可复核、可迭代的样板场景。

**展示文字**
- 第一阶段：数据打通与样板验证。优先建设酿酒预警、包装外观检测、关键设备异常检测。
- 第二阶段：模型上线与业务闭环。形成工艺推荐、缺陷追溯、维修建议、物流仿真优化。
- 第三阶段：跨系统联动优化。打通MES、WMS、SCADA、质检和工单，实现生产数字大脑。
- 第四阶段：企业专属模型沉淀。将工艺知识、专家经验和模型反馈持续训练为企业专属AI能力。

**图中可用标签**
样板验证 -> 业务闭环 -> 系统联动 -> 专属模型

## 9. 价值总结页

**标题**
AI落到生产，最终要体现在质量、效率、成本和经验传承

**页面主句**
算法不是目的，真正的价值是让生产过程更稳定、问题发现更提前、资源调度更高效、经验沉淀更持续。

**展示文字**
- 质量：批次偏离提前预警，包装缺陷在线识别，质量波动可追溯。
- 效率：减少人工判断和重复排程，提高产线、设备、车辆和仓库协同效率。
- 成本：降低停机、返工、误检、空驶、等待和配送里程带来的隐性成本。
- 传承：把专家经验转化为数据规则、模型依据和可复盘的工艺知识库。

**结尾句**
从“人找问题”到“系统提前发现问题”，从“经验靠传帮带”到“经验可沉淀、可计算、可进化”。
