## 当前实验口径

1. 唯一排口：`J132`
2. 20 个候选节点沿通向 `J132` 的主干长路径等间距选取
3. 3 个真值注入点：`J172`、`J89`、`J225`
4. 5 个监测点：`J191`、`J78`、`J59`、`J226`、`J140`
5. 时间窗口：`8` 小时
6. 时间分辨率：`10` 分钟
7. `Q_R` 口径：3 个汇入点注入序列积分汇总
8. 算法：小参数 `GA -> initial PPD -> AM`
