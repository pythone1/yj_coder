# 0323 当前主线说明

## 当前目标

本目录用于构建一个逻辑更严格的 20 节点精细子系统溯源实验。当前版本已经按以下原则重建：

1. 仅保留 8 小时事件窗口参与反演。
2. 使用单一子系统汇出端来计算总入流量 `Q_R`。
3. 注入时间过程不再沿用已知真值模板，而是按 INP 中真实存在的降雨时序 `21` 做等比例时间分配。
4. GA 初始化不再使用任何真值节点，改为真正盲测的随机稀疏种子 + Dirichlet 样本。

## 当前采用的 20 节点子系统

- 真值注入点：`J124`、`J129`
- 监测点：`J226`、`J127`、`J128`、`J130`、`J131`
- 子系统唯一汇出端：`J226`
- 候选节点数：20
- 分析步长：10 分钟
- 事件窗口：8 小时

- 主入口：`运行主流程.py`

## 当前结果状态

最新一轮严格口径结果已经输出到 `results` 目录。需要注意：

- 这版逻辑比之前更严谨；
- 但由于去掉了真值初始化偏置，并把 `Q_R` 改成单一汇出端约束，当前识别难度显著上升；
- 因此当前结果不如旧版“好看”，但更接近真实盲测条件。
