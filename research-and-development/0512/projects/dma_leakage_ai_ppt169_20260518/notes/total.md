# 01_ai_birth

这一部分承接模板正稿，从人工智能概念的形成讲起，强调本次汇报不是单纯讨论工具，而是讨论人工智能如何从理论、算法和数据条件中逐步走向行业应用。

# 02_ai_development

人工智能的发展经历了符号主义、统计学习、深度学习和大模型等阶段。对供水管网场景而言，关键变化在于算法从规则判断转向数据驱动，并开始具备对复杂运行状态的持续学习能力。

# 03_ai_components

人工智能行业应用通常由数据、算法、算力、业务知识和工程系统共同构成。DMA漏损检测正好体现了这种复合特征：既需要管网机理，也需要传感数据、模型训练和运维闭环。

# 04_application_era

进入行业应用阶段后，人工智能的价值不再停留在识别和预测，而是嵌入业务流程，形成监测、诊断、决策和反馈的闭环。后续内容将聚焦供水管网DMA系统这一具体应用。

# 05_dma_topic_cover

本专题围绕AI模型在供水管网DMA系统漏损检测中的应用展开。核心问题是：如何将流量、压力、夜间最小流量、管网资产和工单反馈转化为可解释、可落地的漏损识别能力。

# 06_evolution_timeline

DMA漏损检测的技术路线大体经历四个阶段：经验阈值、统计基线、机器学习识别和智能闭环。当前的重点不是替代原有工程经验，而是把经验规则转化为可持续更新的模型体系。

# 07_dma_unit

DMA分区是漏损检测的基本业务单元。通过边界阀门、流量计、压力点和用户侧用水数据，可以把复杂城市管网拆分成可观测、可比较、可追踪的局部系统。

# 08_ai_access_points

AI进入DMA漏损检测主要有四个切入点：数据清洗、特征构建、异常识别和工单闭环。只有把模型输出接入巡检与维修流程，算法结果才会真正形成管理价值。

# 09_feature_fusion

漏损信号往往不是单一指标异常，而是多源特征共同变化。模型需要融合夜间最小流量、压力波动、天气节律、节假日用水和资产老化等信息，降低误报并提高定位价值。

# 10_dynamic_baseline

动态基线用于解决固定阈值失效问题。不同DMA在季节、用水结构和压力调度上存在差异，因此应建立随时间更新的正常区间，再识别偏离正常运行模式的持续异常。

# 11_unsupervised_labels

供水行业的漏损标签通常稀缺且滞后，完全依赖监督学习并不现实。无监督和半监督方法可以先从大量正常运行数据中学习结构，再对异常片段进行风险提示。

# 12_asset_risk_ranking

模型输出不应只是“是否异常”，还应形成优先级排序。结合管龄、材质、历史维修、压力水平和异常强度，可以把有限巡检资源投向最可能产生收益的DMA或管段。

# 13_mechanism_fusion

可靠的行业AI需要把机理和数据结合起来。水力机理提供边界约束和解释框架，数据模型负责发现复杂模式，两者结合可以提升模型在新区域和异常工况下的稳定性。

# 14_graph_knowledge

管网天然具有图结构。将节点、管段、阀门、泵站、DMA边界和历史事件组织为图谱，有助于表达上下游影响、压力传导关系和故障关联，从而支持更精细的诊断。

# 15_algorithm_matrix

不同算法适合不同任务：统计模型适合基线和阈值管理，机器学习适合多特征分类，深度学习适合时序模式识别，图模型适合空间关联分析。实际项目应按任务组合使用。

# 16_implementation_path

落地路径建议分四步：先做好数据接入和质量评估，再建立DMA基线，其次上线风险评分和预警，最后通过工单反馈持续校准模型。不要一开始追求复杂模型，应先形成可运行闭环。

# 17_data_governance

数据治理是模型效果的前提。需要明确传感器校准、缺失值处理、异常值标注、时间同步和资产台账一致性，否则模型会把数据质量问题误判为漏损风险。

# 18_model_stairs

模型能力可以阶梯式建设：先做监测可视化，再做异常检测，然后做风险评分，最终形成辅助决策。每一级都应有明确评估指标，避免模型展示漂亮但业务不可用。

# 19_validation_bridge

模型验证需要连接离线指标和现场结果。除了准确率、召回率等算法指标，更要关注预警提前量、无效工单率、漏损发现周期和单位巡检收益。

# 20_engineering_workflow

工程化闭环包括数据采集、模型推理、预警分发、现场核查、维修反馈和模型复盘。AI系统的价值来自持续迭代，而不是一次性建模。

# 21_operation_flywheel

当工单、传感和模型反馈持续积累，系统会形成运维飞轮：识别更快、派单更准、反馈更完整、模型更稳定。这是DMA智能漏损管理的长期收益来源。

# 22_conclusion

总体来看，AI模型在DMA漏损检测中的应用价值体现在三点：提升异常识别灵敏度，优化巡检资源配置，推动漏损管理从被动响应转向主动预防。
