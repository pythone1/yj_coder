## 第二章 数据分析
### 2.1 连续性误差是什么
连续性误差不是识别误差，而是 SWMM 在整个仿真时段上的**系统级水量平衡残差**。
它衡量的是：进入系统的总水量，是否能与排出系统的水量、损失掉的水量以及最终留存在系统中的水量闭合。
概念式：`Continuity Error ≈ (总入流 + 初始存储 - 外排 - 损失 - 末时刻存储) / 总入流 × 100%`
### 2.2 连续性误差不是漏算了存储
不是。这里已经把 `Initial Stored Volume` 和 `Final Stored Volume` 都算进去了，而且它们来自 SWMM 报表的系统级存储汇总，不是只统计单独某一个储池点。
- 基线：总入流 `9.319`、末时刻存储 `9.307`、平衡残差 `0.012`（单位均为 `10^6 L`），连续性误差 `0.129%`
- 真值事件：总入流 `32.114`、末时刻存储 `17.103`、平衡残差 `15.011`（单位均为 `10^6 L`），连续性误差 `46.743%`
即便把存储量算进去，真值事件工况下仍然存在很大的系统平衡残差，因此这里反映的是数值水量平衡没有完全闭合，而不是汇报时漏算了存储。
### 2.3 当前数据是否有问题
- 从模板一致性看：truth replay 严格成立，因此模板错配和注水接口错误已经被排除。
- 从数值质量看：基线连续性误差为 `0.129%`，真值事件连续性误差为 `46.743%`，说明事件工况的数值平衡明显更粗糙。
- 从辨识结构看：J140/J145 的强代偿是数据中客观存在的事实，不是算法后处理造成的假象。
- 从参数与布设看：当前问题是 20 候选井、10 监测点、20 维 simplex 份额反演；监测布设已把问题推进到局部簇识别阶段，但尚未唯一切开 J140/J145。

## 第三章 论文适用性分析
### 3.1 中文论文的适用性
- 中文论文更偏工程应用，监测点更多，并且有实地监测/实测数据参与。
- 它更适合解释：为什么监测点更充分、工程信息更完整时，定位结果会更稳。
### 3.2 英文论文的适用性
- 英文论文更偏方法可行性与不确定性分析，典型案例监测点更少，重点是 GA → initial PPD → AM。
- 它更适合解释：为什么在少量监测点条件下，后验会是多峰的、会出现代偿和不确定性。
### 3.3 当前项目与两篇论文的差距
- 当前 0401 项目是一个 20 候选井、10 监测点、20 维 simplex 份额反演问题，网络规模为 239 个节点、239 条连接。
- 相比英文论文的少监测点示例，当前网络更复杂、局部支路更多，代偿更容易出现。
- 相比中文论文的工程监测条件，当前监测信息仍然不够充分，因此还不能等价看作工程上的唯一稳定定位。
- 当前实验最准确的定位是：方法链已经可行，但适用性仍受监测布设、局部支路等效性和事件数值平衡粗糙度的共同限制。
