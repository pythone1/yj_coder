# 当前阶段汇报

## 1. 技术路径

当前方案采用“UWB 主判定 + 视频辅助校验”的双链路结构。

- UWB 主链路
  - 输入：PDOA 上位机 `data.db` 或串口坐标流
  - 处理：轨迹平滑、区域判定、去抖、状态机计数
  - 输出：`A-C`、`B-C` 完整路径计数

- 视频辅助链路
  - 输入：RTSP/USB 摄像头视频
  - 处理：YOLO 检测、多目标追踪、图像区域状态机
  - 输出：辅助路径事件、跨线计数、取证依据

- 融合策略
  - UWB 作为主判据
  - 视频作为辅助校验、异常复核和录像取证
  - 当前阶段不让视频覆盖 UWB 主计数
